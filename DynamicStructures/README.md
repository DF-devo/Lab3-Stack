# Динамические структуры данных

Учебное Windows Forms приложение на C# для изучения стеков, очередей, связных списков и вычисления арифметических выражений.

## Требования

- Windows
- .NET 8 SDK

## Запуск

Откройте PowerShell в папке `DynamicStructures` и выполните:

```powershell
dotnet run
```

Для Visual Studio откройте `DynamicStructures.csproj` и запустите проект (`F5`).

## Возможности

### Стек

- Добавление значения на вершину, снятие верхнего элемента, просмотр вершины и очистка.
- Визуальное отображение элементов стека.
- Пошаговый сценарий с настройкой задержки.

Команды сценария разделяются пробелами или переводами строк:

| Команда | Действие | Пример |
| --- | --- | --- |
| `1,значение` | Добавить значение на вершину | `1,яблоко` |
| `2` | Снять верхний элемент | `2` |
| `3` | Показать вершину | `3` |
| `4` | Проверить, пуст ли стек | `4` |
| `5` | Напечатать содержимое стека | `5` |

Пример: `1,А 1,Б 3 2 5`.

### Очередь

- Добавление в конец, снятие из начала, просмотр первого элемента и очистка.
- Схема очереди с отметками начала и конца.
- Пошаговое выполнение команд и замер времени реализаций на связном списке и `Queue<T>`.

| Команда | Действие | Пример |
| --- | --- | --- |
| `1,значение` | Добавить значение в конец | `1,Ирина` |
| `2` | Удалить первый элемент | `2` |
| `3` | Показать первый элемент | `3` |
| `4` | Проверить, пуста ли очередь | `4` |
| `5` | Напечатать элементы от начала к концу | `5` |

Пример: `1,Анна 1,Борис 3 2 5`.

### Арифметические выражения

- Перевод инфиксной формулы в постфиксную запись и вычисление результата.
- Пошаговое вычисление postfix с отображением стека операндов.
- Загрузка postfix-выражения из текстового файла.

Поддерживаются операторы `+` (сложение), `-` (вычитание), `*` (умножение), `/` или `:` (деление), `^` (степень), скобки, а также функции `sin`, `cos`, `ln`, `sqrt`. В постфиксной записи функции идут после аргумента. Например, `9 sqrt` вычисляет квадратный корень из 9. Десятичная часть числа отделяется точкой.

### Связный список

Программа демонстрирует разворот, перенос первого или последнего элемента, подсчёт различных значений, удаление повторов, вставку в упорядоченный список, удаление заданного числа, присоединение копии списка и разбиение после заданного значения.

## Файлы примеров

- `input.txt` — пример команд стека.
- `postfix.txt` — пример postfix-выражения.

Их можно редактировать или вводить данные непосредственно в окне приложения.
